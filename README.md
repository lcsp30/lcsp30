## 📌 Projetos

### 📚 Trilha do Programador

**Projeto de pesquisa desenvolvido na faculdade e atualmente em desenvolvimento.**

O projeto tem como objetivo desenvolver uma plataforma educativa voltada para **programadores iniciantes**, onde os usuários poderão se cadastrar e resolver desafios de programação utilizando pseudocódigo.

A proposta é tornar o aprendizado de lógica de programação mais acessível, permitindo que iniciantes pratiquem a resolução de problemas sem precisar começar diretamente com a sintaxe de uma linguagem.

🚧 **Status:** Em desenvolvimento
